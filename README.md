# Caledonia Interiors

A one-page site for Caledonia Interiors — Kitchens and Bathrooms, Toll Clock Shopping Centre, Lerwick, Shetland.

Static HTML, no build step. Colours and type are taken from the company logo
(teal `#2B616D` on cream `#F3EFE3`, Cormorant Garamond + Montserrat).

Business details are as published on the company's Facebook page.

Deployed with GitHub Pages from `master`.
